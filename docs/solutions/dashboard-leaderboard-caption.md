# Home leaderboard caption

## Evidence

The Org Dashboard leaderboard badge used `topAccounts.sourceCurated`, which the English catalog still prints as "Curated top 10". Demo curation is a shorter ranking. CI Financial and DNB Bank store `financial_services`, and the row printed that code. The loading skeletons were `aria-hidden`, and a failed read was not an alert.

## Correction

The badge reads `LEADERBOARD_CURATED_CAPTION` ("Curated ranking") through a key the catalog does not own. A stored industry code is printed with `titleCase`. Blank and "Unknown industry" stay a domain, or the portfolio fallback. Loading is a status with `aria-busy`. Failure is an alert with retry. An empty list is a status, separate from the alert.
