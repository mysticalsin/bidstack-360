# Search shows the note sentence that matched

Workspace search finds a note when the query is in the title or the body. The line under the title was the account id. On the demo book that id is the company id, so a search for a word in "Sample: MAHLE test bench review" showed a uuid and not the sentence about the thermal test bench.

The line is now a short excerpt of the body. The match stays near the start of that line. A blank body stays blank. The account id is not printed.
