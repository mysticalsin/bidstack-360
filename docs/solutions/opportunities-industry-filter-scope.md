# Opportunities industry split follows the filter

The collapsed "Pipeline by industry" header reads the territory aggregate: every open bid. A stage, due, or search filter changes the table underneath and left that header on the whole book.

While a filter is on, the header and the opened bars use the rows on this page. A continued page says so. While that list is still loading, the book total stays off the header. With no filter, the header stays the open-book aggregate.
