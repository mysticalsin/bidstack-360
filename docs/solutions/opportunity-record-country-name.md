# An opportunity record names the country the list already named

## Evidence

Demo OP-2041 is CI Financial, country CA, and it has no territory. The opportunities list names that code Canada. The record header printed CA. The rest of the demo book did the same with US, ES, DE, PT, and NO.

## Correction

When the bid has no territory, a real ISO code prints the region name. A territory name still wins. A code that is not a region stays the code. A bid with neither says No country.
