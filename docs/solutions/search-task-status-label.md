# Search names a follow-up status

Workspace search prints the stored task status under the title. Demo follow-ups use `open`, `in_progress`, `blocked`, and `done`. The tasks list already says Open, In progress, Blocked, and Done. The Tasks tab showed the stored token, so "Finalize technical volume for Siemens ERP" read as `in_progress`.

The task row now uses those four words. A status outside that set stays as stored. The link is unchanged.
