# An empty deal-board column is empty, and only a writer can drop

Demo Lead holds no bids. The column said only "Drop here", in small uppercase, including for a role that cannot move a bid. The page header told that same role to drag. A continued page of 50 cards used the same sentence, which would call a stage empty when the board had not loaded every bid.

A finished page says "No bids". A continued page says "None in the latest bids". "Drop one here" is shown only when the role can write opportunities, and that column is not a drop target otherwise. A read-only header says to open the card.
