# Search names a proposal status

Workspace search prints the stored proposal status under the title. Demo proposals use `draft`, `review`, `approved`, `submitted`, `won`, and `lost`. The proposals list already says Draft, In review, Approved, Submitted, Won, and Lost. A Siemens search showed the technical proposal as `review`.

The proposal row now uses those six words. A status outside that set stays as stored. The link is unchanged.
