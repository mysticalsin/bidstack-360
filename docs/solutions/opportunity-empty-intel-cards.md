# Empty opportunity intel is not a report

Demo bids such as Siemens store no intel payload. The deal page still rendered Financial health, Win prediction, Buying triggers, Competitor landscape, and Recent news as dashes, under a line that already said sources had not been queried. An all-null financial object is the same shape: it is not a measured report, and it must not name Crunchbase, LinkedIn, or the EU register.

A card renders only when that card has a signal. A measured zero still counts. A refresh timestamp, a decision-unit member, or a hiring opening keeps the freshness line without inventing the empty cards. Bid score and account intel stay, because they read their own endpoints.
