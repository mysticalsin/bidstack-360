# An unclassified bid does not wear a class

Demo bids such as Siemens store no bid class, no team size, and no commitment. The governance panel on the deal still opened on 5 FTE and medium commitment, and painted that result as the bid's class. A larger placeholder used to read as C3. C3 stays off this path.

A deal with no saved assessment shows that it has no class yet. The class, the committee, the save button, and the gate recorder appear only after team size and commitment are entered, and the gate recorder only after a class is saved. The scratch calculator, with no deal selected, still opens on 5 FTE and medium.
