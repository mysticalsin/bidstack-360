## Part A: Dribbble Job Post

**Title:** Product Designer — B2B SaaS CRM, 4-Week Contract (Remote, Full-Time)

**Job type:** Contract / Freelance  
**Location:** Remote (Worldwide)  
**Duration:** 4 weeks (option to extend)  
**Rate:** $50–$75/hour depending on experience  
**Posted by:** BidStack 360° / Mantu Group  

---

### Description

BidStack 360° is a B2B SaaS CRM for managing bid and presales pipelines, built by Mantu Group (international consulting group, 12,000+ employees). We're launching commercially in 6 weeks and need a sharp product designer to help us complete our design system, create a bespoke icon set, and polish our empty states and brand identity.

**This is execution work, not exploration.** The foundation exists. We need someone who can pick it up fast and ship.

**What you'll own:**
- Audit and complete our Figma component library (gap fill across 12 components)
- Design ~40 custom SVG icons extending our Lucide-based icon set (CRM-specific: pipeline stages, bid status, document states, integration icons)
- Create 6 empty-state illustrations (flat-vector, consistent style)
- Refine the brand logo — 2–3 directions → 1 final + brand guidelines addendum
- Verify dark mode WCAG 2.2 AA contrast across all color tokens
- Deliver Figma Dev Mode annotations + CSS token exports for handoff

**You are a great fit if:**
- Your portfolio shows 2+ enterprise B2B SaaS products (dashboards, data tables, ops tooling — not just marketing pages)
- You have a published icon library or shipped a custom icon set
- You've built or extended a Figma component system with tokens and variants
- Dark mode is second nature for you, not an afterthought
- You are English-fluent and async-comfortable

**Stack context (for handoff):** React 18 + Tailwind CSS 4 + Radix UI primitives. Tokens are CSS custom properties. Dark mode via `data-theme` attribute.

**To apply:** Share your portfolio + a 2–3 sentence note on the most relevant project you've shipped. We respond within 48 hours.
