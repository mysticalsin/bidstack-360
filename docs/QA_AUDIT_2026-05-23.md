## 🔴 CRITICAL

### C-1: Rate Limiting Blocks Dashboard Load in Dev — ✅ FIXED
- **Section:** All pages (dashboard burst load)
- **Steps:** Load dashboard with dev servers running
- **Expected:** All API calls succeed
- **Actual:** Massive 429 errors across `/api/v1/reports/pipeline`, `/api/v1/crm/dashboard`, `/api/v1/opportunities`, `/api/v1/tasks`, `/api/v1/reports/sales-intelligence`, `/api/v1/mentions`
- **Root Cause:** `@fastify/rate-limit` default `API_RATE_LIMIT_MAX=120/min` too low for dashboard's concurrent request burst
- **Fix:** `server.ts` — dev environment rate limit raised to 10,000/min
- **Status:** ✅ Fixed

## 🟡 MEDIUM

### M-1: Framer Motion Animation Warnings on Pipeline
- **Section:** Pipeline (/pipeline)
- **Steps:** Navigate to Pipeline page
- **Expected:** Clean console
- **Actual:** 4 warnings: `"transparent" is not an animatable value` — Framer Motion trying to animate `backgroundColor` from/to "transparent"
- **Impact:** Console noise; may cause visual glitches in animations
- **Fix:** Replace `"transparent"` with `rgba(0,0,0,0)` in animation targets
- **Status:** ⏳ Pending
