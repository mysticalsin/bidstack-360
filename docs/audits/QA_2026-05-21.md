## 🔴 Critical

### C1. API Server Crash on Restart — ESM Import Hoisting Breaks dotenv
- **File:** `apps/api/src/main.ts`
- **Root Cause:** In ESM, all `import` statements are hoisted and evaluated **before** module body code. `dotenvFlow.config()` ran in the module body, but `config.ts` was imported (and evaluated) first, causing `DATABASE_URL: Required` validation failure.
- **Impact:** API cannot restart without pre-exported env vars. Breaks local dev, Docker, and any scripted restart.
- **Fix:** Converted all imports after `dotenvFlow.config()` to dynamic `await import()` calls. ✅ **FIXED**
- **Verification:** `curl http://localhost:4000/api/v1/crm/summary` returns 200 after clean restart.

### H3. Dual Account Referencing (Schema Drift)
- **Files:** `packages/db/prisma/schema.prisma` (`Note`, `FileAttachment` models)
- **Root Cause:** Both models have:
  - `accountId` (VARCHAR) — legacy free-text string
  - `companyId` (UUID FK) — proper foreign key to `Company`
- **Impact:** Confusing data model, potential for orphaned references, query ambiguity.
- **Fix Recommendation:**
  1. Backfill `companyId` from `accountId` where possible
  2. Deprecate `accountId` column
  3. Update frontend to always use `companyId`
  4. Add `NOT NULL` constraint to `companyId` after backfill
- **Status:** Open — requires data migration + frontend updates

## 🟠 Medium

### M1. Frontend API Path Inconsistency
- **Files:** ~15 hooks in `apps/web/src/hooks/` use `/api/...` without `/v1/`
- **Impact:** The backend `rewriteUrl` handles this (`/api/*` → `/api/v1/*`), so it works. But it's fragile — if `rewriteUrl` is removed or changed, all those calls break.
- **Fix Recommendation:** Normalize all frontend paths to `/api/v1/...` in one central place (`api.ts` utility) or bulk-replace across hooks.
- **Status:** Open — code quality, not functional bug

### M2. `console.error` in Production Code
- **Files:**
  - `apps/web/src/components/ErrorBoundary.tsx:29` — logs caught errors
  - `apps/web/src/main.tsx:64` — logs unhandled rejections
- **Impact:** Error details may leak to browser console in production.
- **Fix Recommendation:** Route to Sentry in production, console only in dev.
- **Status:** Open

### M3. React Console Warnings
- **Files:**
  - `TopbarNotifications.tsx` — `Function components cannot be given refs`
  - `RechartsMonthlySalesChart.tsx` — `"key" prop spread into JSX`
- **Impact:** Console noise in development; no functional impact.
- **Fix Recommendation:** Use `React.forwardRef` for Tooltip triggers; pass `key` explicitly before spread.
- **Status:** Open — low priority

### M4. Windows Prisma DLL Lock Blocks `db:generate`
- **File:** `packages/db/generated/client/query_engine-windows.dll.node`
- **Impact:** `pnpm typecheck` fails because `prisma generate` cannot rename the locked DLL. Blocks CI on Windows.
- **Workaround:** Kill all node processes, rename DLL manually, then run `db:generate`.
- **Fix Recommendation:** Add a `pre-generate` script that handles the Windows lock gracefully, or use `prisma generate --generator client` with a custom output path that avoids the lock.
- **Status:** Open — documented workaround exists

### M5. Test Coverage Gaps

### M6. BidNoBidPage setState in useEffect
