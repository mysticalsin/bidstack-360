  (`production-readiness/evidence/2026-06-28/pii-evidence-gates.log`) is `--selftest` lines;

  and **find-by-email silently misses them.**
- **Unblock (ops):** with release-DB access + `PII_ENCRYPTION_MASTER_KEY`, _flag still false_:
  `tsx scripts/encrypt-existing-pii.ts --dry-run` → `--apply` → flip flag → `pnpm deploy:evidence:pii` →
  commit the ciphertext artifact. **Effort M.**

### B2 — No production backup proven to exist (offsite / encrypted / immutable)

- Only a **local** `pg_dump→pg_restore` drill exists. `BACKUP_RESTORE_REPORT.md:26-31` self-declares prod
  backup schedule/encryption/retention/immutability/offsite "None verified." `grep pg_dump|cronjob` over
  `infra/ scripts/ .github/` = **0 hits**; `BACKUP_S3_BUCKET`/`BACKUP_ENCRYPT_KEY` are dead config. Azure
  bicep sets `backupRetentionDays:35` geo-redundant but `main.bicep` is an **unvalidated draft, never run.**
- **Unblock (cloud):** stand up managed-Postgres automated backups + PITR; record
  retention/region/immutability evidence. **Effort L.**
