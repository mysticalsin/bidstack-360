## 1 · Executive headline

**Top 5 risks ranked by exploitability × likelihood:**

1. **`tasks.ts` cross-tenant graft.** `POST /api/tasks` accepts an attacker-supplied `oppId` and writes a task with their own `orgId` — no opp-ownership check. Tenant with a leaked UUID can attach tasks to another tenant's opportunity. (`apps/api/src/routes/tasks.ts:60`)
2. **`webhooks.ts` seed-org fallback runs in production.** If `DUST_WEBHOOK_SECRET` is set but no `WebhookSubscription` row matches, the code falls through to the seed Mantu org regardless of `NODE_ENV`. Anyone with the global secret can forge events into the wrong tenant. (`apps/api/src/routes/webhooks.ts:101-107`)
3. **Apollo worker trusts payload `orgId`.** The BullMQ enrichment job uses `data.orgId` directly to write `CompanyEnrichment` and audit rows. Anyone who can enqueue (or anyone with Redis access) can target an arbitrary org. (`apps/worker/src/queues/company-enrich-apollo.ts:184`)
4. **CSP breaks Clerk + Dust + Sentry on first prod load.** `connectSrc: ["'self'"]` silently kills auth, webhooks, and error reporting. (`apps/api/src/server.ts:67-80`)
5. **Focus ring is invisible on 12+ components.** `ring-[var(--focus-ring)]` consumes a box-shadow value as if it were a color — Tailwind silently fails. Keyboard users see no visible focus. (`apps/web/src/index.css:72`, `KpiTile.tsx:40`, `SalesOrdersPage.tsx:106,123,124,138,145,155,242`, etc.)

**Five biggest architectural lifts:**

1. Extract a `services/` layer out of `routes/` — `crm.ts` is 1590 lines (4× the 400-line cap).
2. Add `Idempotency-Key` middleware + table. Zero POST endpoints support it today.
3. Replace 29 scattered `process.env.X` reads with one Zod-validated `Config` module.
4. Decide twenty-bidstack: extract real modules from the handoff zip, or delete the empty stubs and write `docs/TWENTY_MIGRATION.md`.
5. Split `audit_log.diff` (untyped JSON shared by 5+ writers) — typed per domain, or denormalized into a tagged-union table.

## 5 · Architecture

**Top architectural risks** (from full architecture report):

1. **No service/domain layer.** Six route files violate the 400-line cap; `crm.ts` is 1590 lines, 4× over.
2. **No POST idempotency.** Zero `Idempotency-Key` support across all POST routes.
3. **`packages/twenty-bidstack` is a hollow stub.** 5 files; `bidstack.module.ts` imports submodules that don't exist. CLAUDE.md's "preserve verbatim" guidance protects nothing.
4. **Scattered config.** 29 files read `process.env` directly; no Zod-validated boot.
5. **`audit_log.diff` untyped.** 5 distinct shapes share one JSON column; read back with unsafe casts.
