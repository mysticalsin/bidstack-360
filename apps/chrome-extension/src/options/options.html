Polo PreSales Extension Settings

Connect your CRM account to enable in-browser lead capture

API Configuration

Found in Settings → API Keys inside the Polo PreSales app. The key is stored locally in your browser and never sent to any server except the Polo PreSales API.
Leave blank for cloud. Enter your on-premises URL if self-hosted.

Privacy Notice

This extension stores only your API key and API URL in your browser's local storage (chrome.storage.local). No personal data is collected by the extension itself. Data you submit via the extension is sent directly to the Polo PreSales API endpoint you configured. See the Privacy Policy.
